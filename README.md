#SNAKE GAME
MY SFML 

Simple Snake Game made in C++ with SFML.

## Controls
- **P** - Start Game
- **W** - Up
- **S** - Down
- **A** - Left
- **D** - Right
- **X Button** - Close Game

Eat the red treat to grow. Don't hit wall or yourself.

## How To Play 
1. Download the `snake.zip` from Releases / WhatsApp
2. Extract it
3. Double click `snake.exe`
4. Press **P** to start

No install needed. DLL files must stay next to exe.
